System Architecture

Nova is an enterprise-grade, event-driven data pipeline designed to secure industrial workflows.

  • Watchdog Daemon: Monitors multithreaded landing zones for incoming CSV payloads.
  • HMAC-SHA256 Cryptography: Validates detached signature files against payload byte-streams.
  • DuckDB Medallion Storage: Dynamically creates strictly typed data contracts in a local warehouse.
  • FastAPI & RBAC: Serves queries via decoupled JSON endpoints protected by application-layer Role-Based Access Control.
